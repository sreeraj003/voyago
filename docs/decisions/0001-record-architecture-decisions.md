# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-20

## Context

Voyago will be built over 16 milestones. Decisions made early (stack, structure, conventions) need
to be findable later, with the reasons, by people and coding agents that were not there.

## Decision

Record each significant decision as a short ADR in `docs/decisions/NNNN-title.md` with Status,
Context, Decision and Consequences. Superseded ADRs stay in place and link to their replacement.

## Consequences

Decisions are reviewable in pull requests. Changing a decision means writing a new ADR.
